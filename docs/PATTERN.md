# PATTERN · 格局引擎说明（M5）

> 原则：不输出"系统说这是正官格"，而输出"为什么列为候选、哪些因素支持、
> 哪些破坏、是否存在救应"。status 只是摘要，证据才是本体。

## 1 · 取格（R23/R24）——候选生成

优先级（首条命中即停）：

1. **禄刃优先**：月支 == 日主禄位（临官表）→ 建禄格；月支 == 阳干帝旺位 → 阳刃格。
   - 阴干无刃为通行口径（阴干刃为少数派，本引擎不立，记录争议）。
   - 流派差异：Horosa 以"月令本气为比劫"论禄刃（戊日巳月本气丙不作建禄）；
     Tianze 采用禄位表口径（戊日巳月 → 建禄格候选），差异已写入候选 evidence。
2. **月令藏干透干优先**：按本气→中气→余气顺序，取第一个"同字透出（年/月/时干）
   且十神非比劫"者为首选候选；其后透出者依次保留为次候选（中余同时透场景）。
3. **皆不透 → 取月令本气**（回退口径）。
4. 比肩/劫财**不立正格**：月令藏干为比劫时跳过并记 note；若月支亦非禄刃位
   （如乙日寅月、辛日申月）→ 无正格候选。

每个候选携带：`name / monthBranch / sourceStem / tenGod / via / evidence[] /
provenance[]`。特殊格（从财/从杀/从儿/从强/专旺/化气）**M5 未支持**——不做
伪检测，后续里程碑经 strength verdict 条件化接入。

## 2 · 评估（R25）——证据模型

对**首选候选**运行规则表（其余候选保留未评，冲突记录 PAT-MULTI）：

- **supports**（支持因素）：财生官 / 印护官 / 食神制杀 / 杀印相生 / 食神生财 /
  财旺生官 / 官印相生 / 伤官生财 / 伤官佩印——条件均为相应十神透干（年/月/时干）。
- **damages**（破坏因素）：伤官见官 / 官杀混杂 / 财生杀攻身（无制化时）/
  比劫夺财 / 财破印 / 枭神夺食。
- **rescues**（救应）：印制伤护官 / 官杀制比劫护财 / 官杀通关化财生印 /
  财能制枭护食 / 印制伤——以 `related=[damage rule_id]` 与破坏因素关联；
  damage 与 rescue **允许同时存在**。
- **conflicts**（冲突）：制化两立（食神+印并见，jiwenxu 判破、Horosa 记瑕，
  Tianze 仅记录不裁决）；多候选并存。
