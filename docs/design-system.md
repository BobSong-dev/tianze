# 天泽 · 观象研究室

## 重构依据与边界

2026-11-20：基于实际运行的首页、命盘工作台截图及源码审计制定。面向传统历法、四柱结构的研究者和希望理解结构的新用户；产品是可解释的研究工具，不是吉凶预测服务。

- 技术：Vue 3.5、TypeScript 5.7、Vite 6；无第三方 UI 库、无 Vue Router。`workspace` 驱动会话内 11 个工作区，`useTianze` / `useAiConfig` 管理真实 API 数据。
- 保留现有未提交修改中的业务行为、图谱交互、关系说明、时序回放与受控词汇；不修改后端、API 契约、权限、存储或确定性计算。
- 基线问题：黑底叠加暗角降低对比；渐变、粒子、描金边框抢占注意力；10–13px 正文和复杂卡片影响阅读；首页行动入口偏后；标题晚于大幅四柱出现；弹窗缺少键盘焦点约束。
- 本次不增加数据采集，不展示虚构指标，不把静态节气示意当作实时天象。

## UI UX Pro Max 使用记录

来源：<https://github.com/nextlevelbuilder/ui-ux-pro-max-skill>，安装至用户级 `ui-ux-pro-max` 技能目录。

- `historical research dashboard editorial --design-system` 与收窄后的 `research dashboard --design-system`：匹配 Swiss Modernism 2.0、机构深蓝、研究型衬线标题、编辑式网格。
- 其中 Portfolio Grid 的作品集转化路径不适合研究工具，明确不采用；英文双衬线字体不适合中文密集数据，改用本机宋体标题与系统无衬线正文。
- `keyboard focus modal --domain ux`：采纳可见焦点、焦点不被遮挡、键盘可操作规范。
- Vue 栈检索及一次改写均无匹配，不声称获得框架专项建议；实现遵循项目已有 Composition API 模式及技能通用可访问性规范。

## 视觉方向

以参考图的深靛蓝、古铜金、天文图谱为依据，采用「观象研究室」：编辑式大标题、精密细线、适量留白、可读的数据。保留节气罗盘的文化识别，不复制参考图的神像与装饰。无紫色渐变、玻璃拟态、发光描边、全屏粒子或持续自动旋转。

### 布局与交互

- 首页：文字与无框罗盘双栏，排盘表单紧随首屏，再列研究能力与方法边界。
- 工作台：248px 侧栏；内容最大 1320px；标题先于数据，顶部保留参数与 AI 设置。
- 总览：完整四柱 + 摘要/五行并排。旺衰：多方法比较。格局与高级结构：证据分区。关系：关系列表与图示。调候：目标干与典籍。岁运：控制器、层级时间轨、回放。知识：图谱与检查器、六个研究分区。报告：居中长文、目录与打印。
- 小于 1100px 减少并排区；小于等于 900px 为侧栏抽屉；小于 600px 单列阅读、四柱 2×2、表单堆叠。表格仅在自身容器横滚，整页不横溢。
- 主按钮为铜色实底深字，普通按钮为蓝灰边框，危险状态不用品牌色。表单均有标签与帮助文本；原有输入字段、默认值及校验契约不变。
- 导航以图标 + 文字 + 当前标记呈现，不能只靠颜色。保留全部入口；弹窗支持 Escape、Tab 循环和关闭后焦点恢复。
- 点击、悬停 160ms；页面进入 200ms；不使用无意义循环动画。遵循 `prefers-reduced-motion`。
- 等待状态有说明与忙碌语义；空数据区说明原因；错误保留真实信息与重试入口。不伪造成功。
- 本地确定性分析仍调用当前后端；AI 外发、内存密钥、本机配置权限提示保持可见。

### 会话与反馈规范

- 编辑草稿不改变已提交命例的分析身份；未提交修改必须在工作区明确提示。
- 岁运和 AI 结果绑定提交快照，切换上下文后忽略旧响应，不显示过时的成功结果。
- 报告和打印页须区分 AI 校验通过、失败、未知，不将未知提升为通过。
- 保存/清除失败保留输入与原状态，解除 loading，并提供可被读屏识别的错误提示。
- 知识面板区分请求失败和真实空数据；局部失败不遮蔽已加载数据。
- 打开第二个模态前结束抽屉模态，进入桌面断点时解除移动焦点/滚动锁。
- 时间轨道中干支按双字单元换行，移动原局卡片保留两列空间。
