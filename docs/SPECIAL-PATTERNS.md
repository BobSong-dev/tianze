> M8.1/M8.2 交付。第一原则：高争议区域——**禁止** `if condition: return "从财格"`
> 式结论代码。统一遵循：事实 → 候选 → 支持证据 → 阻断证据 → 例外 → 冲突 → 评估状态。
> 实现位置：`tianze/analysis/special.py`。

## 1 · 从格（M8.1）

### 类型

| 类型 | 定义 | 目标五行 |
|---|---|---|
| 从财 | 日主极弱，顺从财星 | 我克者 |
| 从官杀 | 日主极弱，顺从官杀 | 克我者 |
| 从儿 | 日主极弱，顺从食伤 | 我生者 |
| 从强 | 日主极旺，顺从印比 | 同党 |

### 前置条件（prerequisites）

1. 日主极弱/极旺（weighted/fuyi 至少一项极弱或极强，另一项不高于偏弱/偏强）
2. 日主无根或仅余气微根（jiwenxu 反条件：**明根/暗根即不从**）
3. 异党（或同党）当令且透干成势

### 状态映射（永不 CONFIRMED）

| 条件 | status |
|---|---|
| 分析器冲突（weighted 与 fuyi 方向相反） | DISPUTED |
| 强根（≥2 处）或 有根+印比透干 | BLOCKED |
| 双分析器极弱 + 无根 + 无印比 | LIKELY |
| 有根或印比（但不满足 BLOCKED） | CANDIDATE |
| 证据不足 | UNRESOLVED |

### 阻断因素（blockers）

| 规则 ID | 条件 | 说明 |
|---|---|---|
| SP-CG-B1 | 日主有根（≥1 处） | jiwenxu 反条件：有根不从（强根阻断力度更大） |
| SP-CG-B2 | 印比透干 | 逆从格之势 |

### 冲突因素（conflicts）

| 规则 ID | 条件 | 说明 |
|---|---|---|
| SP-CG-C1 | weighted 与 fuyi 方向相反 | 分析器冲突 → DISPUTED，不判从 |

## 2 · 专旺格（M8.2）

### 五种类型

| 名称 | 五行 | 三会 | 三合 |
|---|---|---|---|
| 曲直 | 木 | 寅卯辰 | 亥卯未 |
| 炎上 | 火 | 巳午未 | 寅午戌 |
| 稼穑 | 土 | 辰戌丑未 | —（四库） |
| 从革 | 金 | 申酉戌 | 巳酉丑 |
| 润下 | 水 | 亥子丑 | 申子辰 |

### 结构条件（非"某五行多就行"）

1. 日干五行与格局五行一致
2. 地支三会/三合成局，或同类干支占绝对优势
3. 天干透出本气
4. 异党（官杀克破）衰微

### 阻断因素

| 规则 ID | 条件 | 说明 |
|---|---|---|
| SP-ZW-B1 | 官杀透干 | 克破专旺最忌 |
| SP-ZW-B2 | 同党占比 <60% | 不成专旺之势 |
| SP-ZW-B3 | weighted 不为极强/偏强 | 旺衰不支持 |

### schoolVariants（流派差异保留）

| 项目 | 口径 |
|---|---|
| Horosa | 同党 ≥85% 且有本气根 |
| ruan | 主导行 >0.75×总量 且 最强他行 ≤0.15 |
| Tianze v1 | 同党可见 ≥60% + 地支同类 ≥3 + 无官杀透干 |
