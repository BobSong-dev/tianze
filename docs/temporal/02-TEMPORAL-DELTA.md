# 02 · 岁运变化对比（TEMPORAL DELTA）

> 当前版本：v1 只输出岁运关系与结构现象，分析器 Delta（旺衰/格局/调候变化）为 EXPERIMENTAL。

## 适用性

| 分析 | 适用性 | 说明 |
|---|---|---|
| 关系 | SUPPORTED | 岁运干支与原局的合冲刑害破 |
| 结构现象 | SUPPORTED | 伏吟/反吟/岁运并临/天克地冲 |
| 三合补齐 | SUPPORTED | 原局 2 支 + 岁运补齐 |
| 旺衰 | EXPERIMENTAL | 岁运加入后重跑 M4 分析器 |
| 格局 | EXPERIMENTAL | 月令取格是否受岁运影响（流派差异大） |
| 调候 | UNSUPPORTED | 调候以出生月令为准，岁运不应改变 |
| 特殊格局 | EXPERIMENTAL | 从格/专旺在岁运下的变化 |
| 病药/通关 | EXPERIMENTAL | 岁运因素是否改变结构矛盾/桥接 |
