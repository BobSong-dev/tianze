# Tianze 试用者交付包（v0.4.0）

> 交给第一批试用者的单页说明。全部本地运行，不上传您的任何数据。

## 这是什么

Tianze（天泽）是一个**开源八字结构分析引擎**：输入出生时间，输出四柱排盘、
五行十神、旺衰（三种方法并列）、格局候选、调候、刑冲合害、大运/流年/流月/流日
的结构变化，并且**每个判断都能展开查看依据**（规则 → 古籍出处 → 页码）。

**它不是什么**：不预测发财/婚姻/疾病等具体人生事件，不给确定人生结论。
所有"候选/LIKELY/DISPUTED"状态都如实标注，流派分歧两说并列。
传统命理不是科学验证的预测体系——本工具是结构分析与古籍知识展示。

## 安装与启动（约 3 分钟）

前置：Python 3.12+ 与 Node.js 18+。

```bash
git clone <仓库地址> tianze && cd tianze
python -m venv .venv
.venv/Scripts/python -m pip install -e ".[api]"   # Windows（macOS/Linux: .venv/bin/python）
cd apps/web && npm install && cd ../..
python scripts/dev_start.py                        # 一键启动
```

打开 **http://localhost:5173**（API 文档在 http://localhost:8000/docs）。

AI 解读（可选）：复制 `.env.example` 为 `.env` 并填入任意 OpenAI 兼容 Key。
**注意**：启用后命盘分析结果会发送到你配置的外部 AI 服务。不配置则全部
功能本地运行，AI 页显示"未配置"。

## 三分钟上手

1. 首页填 **公历出生日期 + 时间 + 性别**（时辰不知道就勾"不知道时辰"，
   会降级并明示）。海外出生请填时区偏移。
2. 点 **分析**：先看"总览"顶部的**分析摘要**（四柱卡片 + 日主 + 格局候选）。
   有看不懂的词？点开"术语与状态说明"。
3. 顶部标签页逐个看：**关系**（合化状态/未成立候选都如实列出）→ **旺衰**
   （三方法并列，分歧不裁决）→ **格局/调候** → **进阶**（特殊格局候选）。
4. 想看岁运：**时序**页选大运和年份 → 点"分析" → 看**逐层状态回放**
   （哪层加了什么、去掉了什么）。
5. 任何结论旁的 **"解释链/成立条件/引文"** 都能展开，一路看到古籍原文。
6. 导出报告：CLI `tianze export --date 1990-01-01 --time 12:00 --gender male
   --format html --out report.html`，HTML 可直接打印（A4 已排版）。

## 阅读结果的三个要点

- **候选 ≠ 结论**：CANDIDATE 是"满足部分条件，需复核"；DISPUTED 是
  "方法/流派有分歧"，两说都给你看。
- **追溯**：每个重要判断都能回答"凭什么"——规则编号、古籍书名章节页码、
  原文摘录。
- **边界**：命例对照是"原书怎么说的 vs 引擎算出什么"，不是"预测准确率"。

## 已知限制（摘要）

- AI 解读需自带 API Key；无 Key 时该功能降级（其余不受影响）。
- 古籍原文的逐字核对基于机器整理（原始扫描未入库），引用标注了出处与
  OCR 风险；发现引文问题请反馈。
- 少数冷门外格（如子邀巳）因原文残缺未启用，页面上不会出现。
- 完整清单见仓库 `docs/known-limitations.md`。
