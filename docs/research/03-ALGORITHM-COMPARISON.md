# 03 · 算法对比（ALGORITHM COMPARISON）

> Phase 0 产出 · 2026-09-30。本文回答：各家旺衰/五行力量/通根/月令/格局/用神/调候**具体怎么算**。
> 全部数值均已核对源码（行号见 `research/notes/*.md`）。凡无传统命理出处的量化常数，一律标注 **[HEURISTIC]**（项目自定权重，不是传统公认数学常数）。
> 结论先行：**六个实现 = 六套互不兼容的量化方案，无任何两家的权重/阈值相同；唯一的行业共识是定性维度（得令/得地/得势、月令最重要、通根分级）。Tianze 不得采信任何一家为"标准"。**

## 1. 旺衰（日主强弱）——六个实现

### 1.1 bazi-atlas（R20-R23，`engine.mjs:745-879`）

- **输入**：四柱可见干支 + 藏干。
- **算法**：每个可见天干（日主除外）为其五行记 1 分；每个地支记主气 1 分 + 每藏干 0.5 分；**月柱全部贡献 ×2**（月令当权）。同类分（比劫+印）/总分 = ratio。
- **阈值**：`{strong: 0.55, weak: 0.45}`，其间中和 [HEURISTIC，注释自认"各派分界不一"]。
- **输出**：`score.perElement + breakdown（逐字计分来源）+ verdict`。
- **特色**：breakdown 逐字可复核；中和**不给用神方向**；168 盘不变量扫描测试。

### 1.2 open-bazi-engine（`analyzer.py:399-481`）

- **算法**（四维加权）：
  1. 得令：日主五行在月支的旺相休囚死，归一化 /4（旺=1.0 … 死=0.0）；
  2. 得地：四支全部藏干中与日主同五行者的个数 /4（余气根与本气根**同权**）；
  3. 得生：四天干中生日主者 /3；
  4. 得助：同五行天干 /3；
  - `score = 0.40×得令 + 0.30×得地 + 0.15×得生 + 0.15×得助` [HEURISTIC]。
- **阈值**：≥0.75 极强 / ≥0.55 偏强 / ≥0.40 中和 / ≥0.25 偏弱 / 否则极弱 [HEURISTIC]。
- **缺陷**：得地计数与五行计数（0.6/0.3/0.1）权重口径矛盾；库内两套权重并存。

### 1.3 ruan-bazi-engine（`build_ui.py` [ENGINE] 区段）

- **算法**：五行加权（天干 1.0；地支本气 1.0 / 中气 0.5 / 余气 0.25；**月令柱整体 ×1.5** [HEURISTIC]）→ 帮扶（比劫+印）vs 克泄耗（食伤+财+官杀）比例。
- **阈值**：ratio >0.6 强 / <0.4 弱 / 其余中和 [HEURISTIC]；专旺格双阈值（主导行 >0.75×总量 且 最强他行 ≤0.15，注释称 2026-08-19 由 0.55 收紧）；从格 support<0.18×总量。
- **特色**：旺衰是 162 条断语的条件键（强/弱/中和三值喂知识库）。

### 1.4 jiwenxu（`yongshen.py:181-258`）——计分制，最复杂

- **输入**：仅 8 个字 + 月支（不含关系、不含大运）。
- **计分步骤（逐步，全部 [HEURISTIC]）**：
  1. 月令得令（`_season_strength`）：月支本气五行 vs 日主五行——同五行 **+3**；生我 **+2**；我生 **+1**；克我 **−1**；我克 **0**；
  2. 天干十神：比劫 **+1.0**、正偏印 **+1.0**、官杀 **−1.0**、食伤 **−0.7**、财 **−0.5**（跳过日干本身，别柱同干比肩计入）；
  3. 藏干（四支全部）：本气 **1.0** / 中气 **0.5** / 余气 **0.25** 为 base；印比 +base；官杀/食伤 −0.5×base；财 −0.3×base；
  4. 母多减子：天干印星 ≥3 时 −0.5×印数（引陆致极，现代流派）；
  5. 假生修正：detect_false_generation 每条强假生 −2.0 / 弱 −1.0；
  6. 十二长生修正：日干在**月支**的长生（长生+2.0 / 临官+2.0 / 帝旺+2.5 / 绝−2.0 …；**注释称含日支，实际只用月支**——文档与实现脱节）。
- **阈值**：score ≥3.5 强 / ≤1.5 弱 / 其间中和（中和带宽 2.0 分）。
- **从格**：**反条件优先**——四柱天干或藏干中出现比劫/印五行即"不从"；从弱 = 弱 且 score≤0.5 且克泄耗计数 ≥75% 总数；按主导十神分从财/从杀/从儿。从旺格有数据**无触发逻辑**（死分支）；从势死分支。

### 1.5 Erfix（`analysis.py:39-48`）——极简（且日柱域失效，仅作算法形态记录）

- support =（日主五行 + 生我五行）/ 全盘加权总分（干 1.0、支主气 1.0、藏干各 0.5）；≥0.5 Strong / ≥0.35 Balanced / 否则 Weak [HEURISTIC]。无月令加权、无通根、无合会。

### 1.6 Horosa（`baziWuxing.js`，176 行）——权重公开可配的"通行示例"

- **五行权重（DEFAULT_WEIGHTS，:12-18，全部 [HEURISTIC]，作者自白："各家权重/阈值无统一标准（这是不同软件自动喜用神打架的根因），故默认给一组透明的通行权重，opts.weights 可整组覆盖"）**：
  | 项 | 值 |
  |---|---|
  | 天干透出 | +100 |
  | 地支本气藏干 | +100 |
  | 地支中气藏干 | +60 |
  | 地支余气藏干 | +30 |
  | 月令乘数 | ×1.5（整月匀加） |
- **日主强弱**：同党 = 印(生我) + 比劫(同我)；ratio = 同党/总；**>0.55 身强 / <0.45 身弱**（:148-152 可配）。
- **三维分列（computeDimensions，:50-94，只展示不回写主评分）**：得令 = 旺相休囚死（旺 40/相 30/休 −10/囚 −20/死 −30，:39 [HEURISTIC]）；得地 = 通根分级（见 §3）；得势 = 年/月/时透干印比 ×20（:88）。
- **分野档**：cangVersion='fenye' 时月柱不再整月 ×1.5，仅"当令司令"之干吃月乘（接 §4.3 分野）。

## 3. 通根 / 得地

- **唯一做了传统分级的是 Horosa**（ROOT_SCORE，baziWuxing.js:46，全 [HEURISTIC]）：禄刃根 30 / 本气库根（辰戌丑未）25 / 本气根 20 / 长生根 15 / 中气根 10 / 余气根 6；**月支根 ×2**（:75）。禄刃/长生支表本身是传统数据，分值是工程化。
- OBE"得地"数根个数（余气=本气同权，粒度最粗）；jiwenxu 无显式通根概念（根通过藏干计分间接体现，全库 grep "通根"只出现在注释）；Atlas/Ruan 不单列。
- **传统口径缺口**：无人实现"天干是否通根到月令本气/中气/余气"与"根是否被冲合损伤"的完整判定。Tianze 的 Root 模型（06 文档）按"禄刃/本气/中气/余气/长生/墓库"六级 + 位置 + 月支标记实现，分值不预置，留给各 StrengthAnalyzer 配置。

## 4. 月令（得令与司令）

1. **旺相休囚死表**（"当令旺·我生相·生我休·克我囚·我克死"）：OBE（branches.json 全 12 支表，四土月土旺金相）、Horosa（SEASON_STATE + 土日主逢四库月特判"四季土旺"）实现一致，属传统规则。Horosa 再叠加打分 40/30/−10/−20/−30 [HEURISTIC]。
2. **月令加权**：Atlas 月柱×2；Ruan/Horosa ×1.5；jiwenxu ±3/2/1——三家三样 [HEURISTIC]。
3. **人元司令分野（节后第几天出干当令）**：只有 Horosa 实现（baziFenYe.js），且**两版并列**——通行版（每月 30 日，余→中→本，如寅=戊7/丙7/甲16）与法诀版（寅=己7/丙5/甲18、卯中气见癸、申分四段、酉见丁、子见辛）。日数各坊本有出入。这是"月令为纲"最细的工程化，Tianze V2 再吸收，V1 记录概念。
4. **月支被冲合是否动摇得令**：只有 Horosa 在格局成败里处理（"月令逢对冲/三刑 → 破格"）；旺衰层无一家处理。
