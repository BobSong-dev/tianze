# Tianze 使用说明（真实用户试用版）

欢迎使用 Tianze（天泽）——一个**可验证、可溯源**的八字结构分析引擎。
本页面向初次使用的用户，说明如何输入、如何阅读结果、哪些内容是确定的、
哪些只是候选或流派分歧。

## 一、它能做什么、不能做什么

**能做**：排出四柱（年月日时），分析五行、十神、旺衰、格局候选、调候、
刑冲合害、大运/流年/流月/流日的结构变化，并给出**每一步判断的依据**
（规则 → 古籍引文 → 来源）。

**不能做**：预测具体人生事件（发财、升职、结婚、疾病、灾祸等），
给出确定的人生结论，或代替任何专业建议。所有"候选 / LIKELY / DISPUTED"
状态都不是定论。

## 二、三步完成一次分析

1. **填写出生信息**：公历日期、出生时间（不知道时辰可勾选"未知"）、性别。
   如出生地在海外，请填时区偏移；如需真太阳时，请提供出生地经度。
2. **点击分析**：首屏"总览"给出日主、五行分布；切换顶部标签页可查看
   关系、旺衰、格局、调候、特殊格局与岁运。
3. **查看岁运**（可选）：在"时序"页选择大运和年份，点击"分析"，
   可查看该阶段的结构变化与逐层状态回放。

## 三、如何阅读结果

- **先看"总览"的分析摘要**：四柱、日主、格局候选、旺衰一致性。
- **状态词汇表**（也内置在页面中）：
  - 候选（CANDIDATE）：满足部分条件，需复核，**不是结论**。
  - LIKELY / DISPUTED：支持证据占优 / 方法与流派存在分歧（两说并列）。
  - BLOCKED / UNRESOLVED：有明确阻断 / 证据不足。
  - EXPERIMENTAL：该计算在流派上有分歧，仅作参考。
- **每个重要判断都可以展开**："解释链""成立条件""引文"会显示
  规则编号、古籍出处（书名/章节/页码）与原文摘录。
- **报告导出**：CLI 支持导出 Markdown 与 HTML（HTML 可直接打印，
  已做 A4 打印排版）。

## 四、常见术语速查

| 术语 | 通俗解释 |
|---|---|
| 日主 | 出生日的天干，代表命局分析的出发点 |
| 旺衰 | 日主力量的强弱的多种评估方法（并列呈现，不强行裁决） |
| 格局候选 | 传统命理对结构类型的归类候选（如正官格、从财格） |
| 调候 | 按出生月令对五行寒暖燥湿的调节建议 |
| 从格 / 专旺 / 化气 | 三类特殊结构候选；判定条件严格，多数盘只会是"候选" |
| 虚神 / 填实 | 拱夹关系中"缺少的那个字"；岁运遇到即"填实" |
| 争合 | 多个同类天干竞争同一个合 partners（如二己争一甲） |

## 五、使用边界与免责

- 本工具是**结构分析与古籍知识展示**工具，不构成任何人生建议、
  医疗建议、投资建议或现实预测。
- 引擎的判断来自公开古籍的结构化整理，存在流派分歧时**两说并列**，
  不代表任何一派"正确"。
- 所有候选状态都可能随证据更新而调整；请勿基于本工具输出做重大人生决策。
