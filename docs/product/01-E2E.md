# 01 · E2E 测试（Playwright）

> 配置：`apps/web/playwright.config.ts`
> 场景：`apps/web/e2e/*.spec.ts`
> 运行：`cd apps/web && npx playwright test`

## 场景覆盖

| 文件 | 场景 |
|---|---|
| normal.spec.ts | 正常命例 → 四柱出现 → 旺衰三方法 → 格局 → 调候 → 高级结构 |
| unknown-time.spec.ts | 未知时辰 → partial result + warning 可见 |
| late-zi.spec.ts | 晚子时 sect1/sect2 → 日柱不同、时柱相同 |
| overseas.spec.ts | 海外时区（NYC -4）→ 正常出盘 |
| invalid-input.spec.ts | 无效日期 → error 可见（不 crash） |
| explainability.spec.ts | 旺衰 → 展开证据 → evidence-item 可见 |

## 启动方式

Playwright `webServer` 自动启动 uvicorn :8000 + Vite dev :5173。
